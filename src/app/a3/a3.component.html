A3: Pokedex in JavaScript

In this assignment, you will apply programming principles in JavaScript to create an interactive Pokedex. Many such pokedexes exist, such as Bulbapedia. Here, we'll leverage the PokeAPI to create a fairly simple pokedex for the original 151 Pokemon.

This assignment is in three parts, with a part due every 1-1.5 weeks. In the first part (Part 1), you will use JavaScript to dynamically populate a Pokedex entry with some information about the Pokemon. In the second part (Part 2), you will use loops and functions to populate the Pokemon's stats and moves. In the third part (Part 3) you will update the main page of your Pokedex to include search and filter features. This assignment is worth 25 points, split between the three parts.

Starter code

The code is available for download on GitHub.

Repository Structure

We have provided a folder with a number of files to you. You will edit some of them in this assignment, but not all.

The files you should not need to edit are:

  • The media folder, which includes default (Missingno) images and specifies the icon to render in your browser bar.
  • index.html. This file includes the visual information for how the Pokedex page is structured.
  • pokedex.html. This file includes the visual information for how a Pokemon's page is structured.
  • style.css. This file includes styling information for the webpage.
  • pokemon.js, which leverages the PokeAPI to access data about specific Pokemon.
  • utility.js, which includes a few helper functions.

Note that this means you should not edit any HTML or CSS files, and only need to edit a subset of JavaScript files. You may choose to, but only for adding functionality beyond the assignment requirements.

The files you should edit are:

  • pokemon_page.js: The JavaScript file for Pokedex entries, which you will use in Parts 1 and 2.
  • search_page.js: The JavaScript file for the search features of the Pokedex, which you will use in Part 3.
  • readme.docx: A document with some questions to fill out about your experience adding the search and filter features.
